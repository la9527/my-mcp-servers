작성일: 2026-09-15
상태: 권장안 승인 완료(2026-09-15). 03 기본 Story + 04 선택형 공간 테마 + 01 공통 뷰어로 구현 진행.
이 폴더의 이미지는 계속 정적 콘셉트이며 실제 제품 캡처가 아니다. 02/05는 후속 후보로 보존한다.

## 이번 재설계의 기준
사용자는 기존 디자인이 단조롭고 과도하게 컬러풀하며 사용하기 어렵다고 평가했다.
색상 교체가 아닌 감상 구조, 사진 이동 방법, 이야기의 전개 방식이 다른 다섯 시안을 비교한다.
이미지는 imagegen으로 생성한 정적 UX 콘셉트이며 실제 서비스 캡처·동작 검증 결과가 아니다.
사진과 문구·날짜·장수는 가상 예시다. 실제 가족 사진을 이번 생성에 업로드하지 않았다.

## 5가지 방향
| 안 | 화면 구조 | 기본 탐색 | 이야기 표현 | 예상 구현 부담 |
|---|---|---|---|---|
| 01 고요한 추억 | 큰 사진 1장 + 작은 필름스트립 | 좌우 스와이프 / 썸네일 선택 | 사진 아래 짧은 문장 | 낮음~중간 |
| 02 순간의 묶음 | 장면별 비대칭 사진 묶음 | 장면 선택 → 사진 순차 감상 | 장면 제목 + 짧은 설명 | 중간 |
| 03 스크롤 시네마 | 사진과 문장이 이어지는 세로 이야기 | 일반 세로 스크롤 | 장면 전환에 맞춘 문장 | 중간~높음 |
| 04 공간을 흐르는 사진 | 곡선 경로의 입체 사진 평면 | 드래그 → 중앙 정렬 → 선택 | 장면 타임라인 + 선택 사진 설명 | 높음 |
| 05 펼쳐보는 기억의 책 | 입체 양면 사진집 | 책장 넘김 / 목차 이동 | 한 펼침면이 한 장면 | 높음 |

예상 부담은 설계 판단이며 저장소 구현 가능성 및 기기 성능을 실측한 견적은 아니다.

## 04안: 직접 설계한 공간 구조
- PC에서는 중앙 사진 1장과 좌우 주변 사진을 합해 약 5~7장을 우선 표시한다.
- 중앙 사진은 정면 평면이며 원본 종횡비를 보존한다. 주변 사진만 얕은 곡선 경로와 원근을 가진다.
- 초기 회전 범위는 약 8~15도 수준에서 프로토타입으로 조정한다. 시안은 수치가 정확한 기하 설계도가 아니다.
- 좌우 드래그로 이전/다음 사진이 중앙으로 이동한다. 선택한 사진은 공통 평면 뷰어로 열린다.
- 모바일은 3장 정도의 얕은 깊이로 축소한다.
- 자동 카메라 비행·무한 회전·마우스 움직임에 과도하게 따라가는 효과는 적용하지 않는다.
- 이미지 내부 깊이 추정/인물 분리/배경 생성은 기본 범위에 포함하지 않는다.
- 성능 저하나 모션 감소 설정에서는 평면 스와이프 목록으로 대체한다.

## 05안: 책장형에서 지켜야 할 사항
- 사진은 책 중앙 접힘선에 걸치지 않게 배치한다.
- PC는 양면, 모바일은 한 페이지로 재배치한다.
- 책장 효과는 전환에만 적용하며 감상 중에는 페이지를 안정적으로 고정한다.
- 이미지를 누르면 종이/원근 효과가 없는 공통 사진 뷰어로 연다.
- 목차로 원하는 장면에 바로 이동한다. 모든 페이지를 순서대로 넘기도록 강요하지 않는다.

## 모든 테마 공통 UX 계약
1. 사진 감상과 관리 기능 분리. 재분석·인물 검토·삭제는 관리 화면에 둔다.
2. 한 장 보기 최초 진입은 화면에 맞춤, 확대 상태가 다음 사진에 남지 않도록 설계.
3. 사진 한 장 보기에서 좌우 이동·핀치·더블탭·닫기·사진 위치 표시 제공.
4. 확대 중에는 사진 내부 이동, 기본 배율에서는 사진 간 이동으로 충돌을 방지.
5. PC 키보드 좌우와 Escape, 터치, 포커스 복귀, 안드로이드 시스템 바 보존.
6. 공통 위치/인물/다운로드 정보는 별도 정보 패널로 열며 감상 화면을 덮어 쌓지 않는다.
7. 녹색 포인트와 강한 배경색을 기본값으로 사용하지 않는다. 색은 주로 실제 사진이 만든다.
8. 자동 재생은 사용자가 시작한 경우만. 모션 감소와 낮은 성능에서 정적/평면 대체 제공.
9. 선택/목록 복귀 때 장면·스크롤 위치를 보존한다.
10. 세로 사진·가로 사진·파노라마·여러 장·사진 부족·정보 없음 상태를 각각 검증한다.

## 권장 의사결정
- 이야기 전달과 일상 사용 균형: 03안을 기본 Story 후보로 비교.
- 쉽고 익숙한 사진 감상: 01안을 공통 한 장 보기의 기반으로 사용.
- 개성이 중요한 선택형 테마: 04안을 우선 3D 프로토타입 후보로 비교.
- 02안은 장면 탐색, 05안은 가족 사진집 읽기에 특화.
사용자 선택 전에는 이 제안을 확정하거나 제품에 적용하지 않는다.

## 승인 이후 순서
1. 선호하는 전체 방향 1~2개와 수정할 요소 확정.
2. 확정한 방향의 PC/모바일 상세 상태 및 움직임 프로토타입 제작.
3. 사진 화면맞춤·스와이프·확대 충돌·뒤로가기·지도/정보 패널·로딩을 검증.
4. 실제 사용자 사진을 로컬에서 적용해 시각 확인.
5. 승인한 공통 UX와 테마를 제품에 통합, 회귀 테스트 후 배포.
