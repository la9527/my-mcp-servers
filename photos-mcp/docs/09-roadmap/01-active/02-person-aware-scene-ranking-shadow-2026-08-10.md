# 인물 구성 기반 장면 분리와 얼굴 품질 추천

## 상태

- 검토와 첫 shadow 계측 완료
- 314장 얼굴 임베딩·표정·Apple 얼굴 품질 계측 완료
- 인물 구성 분리는 shadow 유지, 얼굴 점수 순위 반영은 첫 실험에서 기각
- 얼굴 결함 veto shadow 완료, 교체 정책은 개선을 입증하지 못해 운영 반영 기각
- 동일 인물 pairwise VLM shadow 완료, mirror-consensus는 개선 가능성만 확인하고 운영 승격 보류
- 전용 인물 구성 라벨 UI와 SFace calibration CLI 구현 완료, 실제 라벨 수집 대기
- 실제 1,000장 작업의 사람 검토 완료 장면을 기준선으로 사용
- 운영 장면 묶음과 추천 결과는 검증 통과 전까지 변경하지 않음

## 문제

현재 장면 묶음은 촬영 시각과 전체 이미지의 Apple Vision FeaturePrint 유사도를 중심으로 만든다. 인물 정보는 이미 확인된 이름이 있을 때만 보조적으로 사용하므로 다음 두 경우를 충분히 구별하지 못한다.

1. 같은 시간과 배경에서 서로 다른 사람을 촬영한 사진
2. 같은 시간, 배경과 사람이지만 표정·시선·눈 감김·얼굴 선명도가 다른 연속 사진

현재 실행 환경의 얼굴 backend는 MediaPipe FaceDetector다. 얼굴 위치는 찾지만 인물 임베딩과 정량 표정 신호를 생성하지 않는다. 실제 1,000장 작업에서도 인물 임베딩과 확인 인물은 저장되지 않았다. 따라서 얼굴 수가 같아도 같은 사람인지 확인할 수 없으며, 얼굴 수나 VLM의 자연어 표정만으로 추천을 강화하면 단체사진과 배경 사진을 잘못 평가할 수 있다.

## 목표

장면을 한 번에 나누지 않고 세 계층으로 분리한다.

| 계층 | 기준 | 결과 |
| --- | --- | --- |
| 장면 가족 | 촬영 시각, 전체 배경과 구도 | 같은 행사·장소의 사진 묶음 |
| 인물 구성 그룹 | 익명 얼굴 임베딩 집합 | 배경이 같아도 등장 인물이 다르면 별도 비교 그룹 |
| 연속 촬영 변형 | 같은 인물 구성과 유사 구도 | 표정·시선·얼굴 품질로 순위를 정할 후보 |

인물 이름은 필요하지 않다. 얼굴 임베딩은 작업 내부의 익명 cluster ID로만 사용하고, 사용자 확인 전에는 이름이나 관계를 추론하지 않는다.

## 핵심 정책

### 인물 구성 분리

- 얼굴 임베딩이 충분히 일치하는 얼굴만 같은 익명 인물로 묶는다.
- 인물 집합이 같은 사진은 동일 인물 구성 그룹으로 본다.
- 인물 집합이 다르면 장면 가족은 유지하되 서로 다른 인물 구성 그룹으로 분리한다.
- 얼굴이 없거나 검출 신뢰도가 낮은 사진은 `unknown` 그룹으로 유지하며 다른 인물 그룹에 강제로 합치지 않는다.
- 단체사진에서 일부 얼굴이 누락될 수 있으므로 얼굴 수만으로 인물 구성을 확정하지 않는다.
- 사진 내 최대 얼굴 크기의 50%보다 작은 얼굴은 기본적으로 배경 행인 후보로 보고 인물 구성에서 제외한다. 실제 장면 경계 라벨로 이 비율을 재조정한다.
- 같은 사진 안의 서로 다른 얼굴은 임베딩이 유사해도 하나의 인물로 합치지 않는다.

### 동일 인물 그룹 순위

인물이 있는 사진은 다음 얼굴 중심 점수를 같은 인물 구성 그룹 안에서만 상대 비교한다.

| 신호 | 초기 비중 | 설명 |
| --- | ---: | --- |
| 얼굴 촬영 품질 | 30% | Apple Vision Face Capture Quality |
| 눈 감김·카메라 시선 | 25% | MediaPipe 얼굴 landmark와 blendshape |
| 미소·자연스러운 표정 | 20% | 좌우 미소와 과도한 입 벌림을 분리해 평가 |
| 얼굴 선명도·노출 | 10% | 얼굴 crop의 선명도와 밝기 |
| 얼굴 가림·고개 각도 | 10% | landmark 누락과 pose 편차 |
| 얼굴 크기·배치 | 5% | 화면 내 인물 크기와 중심 배치 |

단체사진은 평균만 사용하지 않는다. 가장 낮은 얼굴 점수와 하위 25% 평균을 함께 사용해 한 사람만 눈을 감거나 흐린 사진도 감점한다. 전체 프레임의 기술·미학 점수는 얼굴 점수가 비슷할 때의 보조 정렬값으로 사용한다.

### 추천 수

- 같은 인물 구성과 배경에서는 기본 추천 1장을 선택한다.
- 표정, 포즈 또는 구도가 충분히 다른 경우에만 2번째 대안 후보를 허용한다.
- 서로 다른 인물 구성 그룹은 서로 경쟁시켜 제거하지 않고 각 그룹의 대표를 계산한다.
- 최종 화면에서 장면 가족과 인물 구성 그룹의 관계를 설명할 수 있도록 선택 이유를 보존한다.

## 기술 선택

### 인물 임베딩

초기 shadow backend는 OpenCV YuNet과 SFace를 사용한다.

- OpenCV 4.10 이상과 5.x에서 native API 제공
- SFace 모델 약 36.9MB
- 모델 디렉토리의 Apache 2.0 라이선스 확인
- 공식 cosine 기준값 `0.363`을 시작점으로 사용하되 개인 사진 표본에서 보수적으로 재조정
- 모델과 임베딩은 `~/.photos-mcp` 아래 개인 캐시에만 저장

InsightFace는 코드상 우선 backend로 작성돼 있지만 현재 환경에 설치되지 않았고 제공 사전학습 모델의 사용 조건을 별도로 검토해야 한다. 이번 shadow 기본값에는 사용하지 않는다.

### 얼굴 품질과 표정

- Apple Vision `VNDetectFaceCaptureQualityRequest`: 얼굴 촬영 품질
- MediaPipe Face Landmarker: 478개 landmark와 52개 blendshape
- OpenCV 얼굴 crop: Laplacian 기반 상대 선명도와 밝기
- VLM `expressions`와 `quality_notes`: 정량 신호가 없을 때만 보조 설명으로 사용

## Shadow 검증 설계

### 데이터

- 입력 작업: 실제 1,000장 작업
- 사람 검토 큐: 복수 사진 장면 140개
- 평가 장면: 사람 1순위가 있는 완료 장면 116개
- 예상 계측 사진: 중복을 제거한 미리보기 약 314장
- 원본과 Apple 사진은 읽기 전용이며 복사·변경하지 않음

### 비교 항목

1. 현재 저장된 Top-1과 Top-2 기준선을 재생한다.
2. 각 장면에서 얼굴 검출률과 임베딩 생성률을 측정한다.
3. 인물 구성 차이로 둘 이상으로 나뉘는 장면 수를 측정한다.
4. 사용자 1순위와 현재 자동 1순위의 인물 구성이 다른 장면을 측정한다.
5. 사용자 1순위가 속한 인물 구성 그룹 안에서 얼굴 품질 shadow 순위를 계산한다.
6. 현재 순위와 shadow 순위의 Top-1, Top-2 포함률과 변경 장면을 비교한다.
7. 변경 장면 일부는 개인 audit 파일로만 저장해 실제 사진을 눈으로 확인한다.

### 출력 개인정보

Git에 저장할 집계에는 사진 ID, 원본 경로, 얼굴 box, 임베딩과 개인별 점수를 넣지 않는다. 개인 audit은 다음 경로에만 저장한다.

```text
~/.photos-mcp/validation/person-aware-scene-shadow/<job-id>/
```

## 승격 조건

운영 로직은 다음 조건을 모두 충족한 뒤에만 변경한다.

1. 평가 사진의 얼굴 임베딩 생성 실패율이 10% 이하이거나 실패 사유가 명확히 격리된다.
2. 인물 구성이 다른 장면의 사람 확인 표본이 최소 30개다.
3. 다른 사람을 같은 연속 촬영 그룹으로 합치는 오류가 5% 이하이다.
4. 동일 인물 구성 그룹의 사람 Top-1 일치율이 현재보다 최소 5%p 개선된다.
5. 전체 Top-2 포함률 손실이 1%p 이내이다.
6. 눈 감김·표정 때문에 사람이 선택한 사례에서 개선과 악화가 각각 집계된다.
7. 1,000장 전체 회귀, AppKit 결과 화면과 내보내기 회귀가 통과한다.

인물 구성 SFace 보정은 라벨이 각 30개 이상인 `sample_ready` 단계와 운영 후보가 될 수 있는 `promotion_ready` 단계를 분리한다. `promotion_ready`에는 위 오류 한도에 맞춰 다른 주요 인물 분리 재현율 95% 이상이 필요하며, 같은 주요 인물 정확도도 90% 이상이어야 한다. 임의·편향 라벨은 표본 수를 채워도 운영 기준값을 만들 수 없다.

조건을 통과하지 못하면 모델과 신호를 운영 DB에 저장하지 않고 shadow 결과만 유지한다.

## 첫 shadow 결과

사람 검토 완료 116장면의 미리보기 314장을 계측했다. 302장에서 986개 얼굴 임베딩을 생성했으며 0.45 기준 주요 인물 필터 적용 후 60장면이 191개 인물 구성 그룹으로 나뉘었다.

인물 구성 분리는 실제 다른 등장 인원과 배경 행인을 구분할 가능성을 확인했지만 사람 경계 라벨이 없어 승격하지 않았다. 얼굴 점수를 강하게 반영한 동일 인물 순위는 Top-1이 75.00%에서 54.69%로 하락했다. 기존 점수에 0.05점만 더한 보수적 후보도 73.44%로 낮아졌다. 운영 순위는 변경하지 않는다.

상세 수치와 시각 확인 결과는 [인물 구성 기반 장면 분리와 얼굴 품질 shadow 검증](../../08-reports/01-validation/11-person-aware-scene-shadow-2026-08-10.md)에 기록했다.

눈 감김·심한 흐림·낮은 얼굴 촬영 품질만 사용하는 후속 veto 시험도 완료했다. SFace cosine `0.45` 기준 strict 정책은 변경이 없었고, conservative와 balanced 정책은 각각 2장과 3장을 바꿨지만 사람 Top-1 일치율을 `75.00%`에서 `73.44%`, `71.88%`로 낮췄다. 절대 임계값 기반 교체는 기각하고 동일 주요 피사체 후보의 pairwise 비교를 다음 shadow 단계로 진행한다.

동일 주요 피사체 32쌍에 Linux Qwen3.6 pairwise 비교도 완료했다. 단일 요청은 B 위치 편향이 `63.92%p`로 커서 기각했다. 정방향과 역방향이 같은 실제 사진을 선택할 때만 인정한 mirror-consensus는 기준선보다 `18.75%p` 높았지만 21쌍을 보류했고 위치 격차도 `33.73%p`였다. 운영 반영은 보류하며 상세 결과는 [pairwise VLM shadow 검증](../../08-reports/01-validation/12-person-pairwise-shadow-2026-08-11.md)에 기록한다.

## 구현 순서

1. 인물 임베딩과 익명 인물 구성 그룹의 순수 분석 모듈을 추가한다.
2. OpenCV SFace, Apple Vision과 MediaPipe 계측 CLI를 추가한다.
3. 합성 임베딩으로 동일 인물·다른 인물·부분 단체사진 단위 테스트를 작성한다.
4. 116장면에 shadow CLI를 실행해 비식별 보고서와 개인 audit을 만든다.
5. `인물 구성 검토`에서 같은 주요 인물·다른 주요 인물·배경 행인·검출 불가 라벨을 보강하고 SFace 기준값과 주요 얼굴 면적 비율을 재생한다.
6. 동일 주요 피사체 후보의 pairwise 얼굴·표정 비교를 별도 shadow로 측정한다.
7. 승격 조건을 통과한 뒤에만 `scene_selection`과 제품 추천 순위에 반영한다.
