# 개인 얼굴 관리 UI

## 목적

사진 분류 결과에서 감지된 얼굴을 개인 로컬 화면에서 묶어 확인하고, 사용자가 직접 이름을 지정하거나 잘못 묶인 얼굴을 분리·병합한다. 이름과 관계는 자동 추론하지 않는다.

## 개인정보 원칙

- 원본 사진, 얼굴 crop, 경로, 임베딩은 Git과 결과 JSON에 넣지 않는다.
- 이름과 수동 편집 연결은 `~/.photos-mcp/people/people-private.json`에만 저장하고 권한을 `0600`으로 제한한다.
- 화면에서 쓰는 얼굴 crop은 기존 개인 검토 cache를 재사용한다.
- 이름, 병합, 분리, 삭제는 Apple 사진과 Google Photos 원본을 변경하지 않는다.

## 화면 흐름

1. 왼쪽 목록에서 자동 얼굴 묶음 또는 이름이 지정된 인물을 고른다.
2. 오른쪽에서 얼굴 crop을 선택하고 이름을 저장한다.
3. 선택 얼굴은 새 인물 묶음으로 분리할 수 있다.
4. 현재 묶음은 다른 묶음과 병합할 수 있다.
5. `이름과 수동 변경 지우기`는 개인 레지스트리의 override만 제거하고 자동 묶음으로 되돌린다.

## 초기 범위

- 최근 완료된 분류 작업의 로컬 얼굴 계측 결과만 읽는다.
- 고신뢰 자동 묶음은 시작점일 뿐이며, 사용자 편집을 우선한다.
- 새 분석 결과의 미확인 얼굴은 자동 묶음으로 표시하고, 기존 이름을 자동 확정하지 않는다.

## 검증

- 레지스트리 저장 권한과 Git 미포함을 단위 테스트한다.
- 이름 지정, 얼굴 분리, 묶음 병합, 수동 변경 삭제가 재로딩 뒤 유지되는지 확인한다.
- AppKit 탭에서 빈 상태, 얼굴 선택, 이름 저장과 병합 대상 선택을 검증한다.
