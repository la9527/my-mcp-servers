# 추천 품질 사람 검토

## 상태

- 앱·저장·집계 구현 완료
- 실제 1,000장 결과에서 140장면·542장 연결 및 설치 앱 검증 완료
- 사람 기준선: 116장면 검토 완료, 24장면 건너뜀
- shadow 가중치 평가 완료: 현재 운영 순위 유지
- 두 번째 추천 다양성 shadow 완료: pHash 후보는 표본 부족으로 보류

## 목표

자동 추천이 사용자가 실제로 고르는 사진과 얼마나 일치하는지 장면 단위로 측정한다. 모델 점수나 추천 임계값을 먼저 바꾸지 않고, 현재 `relative_scene_top_2` 결과를 사람 정답과 비교하는 검증 데이터를 축적한다.

## 1단계 구현

결과 갤러리의 `추천 품질 검토` 버튼에서 복수 사진이 있는 장면만 순서대로 연다.

- 사진 클릭 또는 숫자 키: 사람 평가 1순위
- `2순위` 버튼 또는 `Shift+숫자`: 필요한 경우 두 번째 사진
- `크게 보기`: 기존 전체 화면 뷰어에서 원본 확인
- 장면 묶음: 같은 장면, 서로 다른 장면, 판단 보류
- 실패 이유: 눈 감김, 흐림, 표정, 유사 사진 중복, 기타
- `Enter`: 현재 선택을 저장하고 다음 장면으로 이동
- 좌우 방향키: 이전·다음 장면 이동

검토는 현재 작업 결과를 수정하지 않으며 Apple 사진이나 원본 파일에도 쓰지 않는다. 사람 선택은 작업별로 다음 개인 경로에만 저장한다.

```text
~/.photos-mcp/validation/recommendation-quality/<job-id>/review-private.json
```

디렉터리는 `0700`, 큐 파일은 `0600` 권한을 사용한다. 사진 식별자와 로컬 경로가 들어 있으므로 Git이나 공개 보고서에 포함하지 않는다.

## 집계 지표

UI는 검토 진행률과 다음 집계를 실시간으로 표시한다.

| 지표 | 의미 |
| --- | --- |
| 자동 1순위 적중률 | 사람의 1순위와 자동추천 1순위가 같은 장면 비율 |
| 자동 Top-2 포함률 | 사람의 1순위가 자동추천 두 장 안에 포함된 장면 비율 |
| 사람 선택 재현율 | 사람이 고른 1~2장 중 자동추천이 포함한 비율 |
| 자동추천 정밀도 | 자동추천 두 장 중 사람이 실제로 고른 비율 |
| 장면 경계 집계 | 잘못 합쳐진 장면과 판단 보류 개수 |
| 실패 이유 집계 | 눈 감김·흐림·표정·중복 등 오류 유형 개수 |

공개 가능한 집계에는 사진 ID, 경로와 개별 사진 점수를 넣지 않는다.

## 다음 단계 조건

최소 50개 복수 사진 장면을 검토한 뒤 현재 기준값을 고정한다. 그 전에는 추천 점수에 학습값을 반영하지 않는다.

1. 자동 1순위 적중률과 Top-2 포함률을 기준선으로 기록한다.
2. 오류 유형별로 얼굴 품질, 선명도, 구도와 중복 억제 신호를 shadow score로 계산한다.
3. 같은 검토 데이터를 사용해 기존 순위와 shadow 순위를 비교한다.
4. 개선이 확인된 신호만 실제 추천에 제한적으로 반영하고 1,000장 회귀를 다시 실행한다.

## 2단계 결과

사용자가 복수 사진 장면 140개를 모두 확인했다. 이 중 정답 1순위가 있는 116개를 평가에 사용했고 24개는 건너뛰었다. 모든 완료 장면은 같은 장면 묶음으로 확인됐으며, 명시적인 실패 원인은 유사 사진 중복 4건이었다.

| 평가 | Top-1 | Top-2 포함 | MRR |
| --- | ---: | ---: | ---: |
| 현재 운영 순위 | 68.97% | 93.10% | 0.8302 |
| 가장 좋은 고정 shadow `의미 점수` | 67.24% | 93.97% | 0.8230 |
| 35개 후보 5겹 교차검증 | 60.35% | 93.97% | 0.7879 |

품질·기술·가족·이벤트·의미 점수의 조합은 Top-2 포함률을 최대 94.83%까지 높였지만 Top-1은 59.48~64.66%로 낮아졌다. 가장 좋은 고정 후보도 Top-1이 1.73% 감소했고 95% 신뢰구간은 `-7.76%~+4.31%`로 개선을 입증하지 못했다.

승격 조건은 Top-1 2% 이상 개선, Top-1 차이의 95% 신뢰구간 하한 양수, Top-2 손실 1% 이내를 동시에 만족하는 것이다. 통과한 후보가 없으므로 운영 가중치와 추천 결과는 변경하지 않는다.

재현 가능한 집계 도구는 `scripts/analyze_recommendation_review.py`에 추가했다. 입력 큐에는 사진 ID와 경로가 있지만 출력에는 개별 식별자를 넣지 않는다. 상세 결과는 [사람 기준선 및 shadow 점수 검증](../../08-reports/01-validation/09-recommendation-shadow-score-2026-08-10.md)에 기록한다.

두 번째 추천은 별도 `scripts/analyze_recommendation_diversity.py`로 Apple Vision 거리와 pHash를 재생한다. `Vision 0.008 + pHash 0.08`이 중복 추천 1건을 제거하면서 Top-2 손실을 0.86%로 제한했지만 명시적 중복 라벨이 4개뿐이므로 운영 반영을 보류했다. 최소 20개 중복 라벨을 확보한 뒤 재평가한다. 상세 결과는 [두 번째 추천 시각적 다양성 shadow 검증](../../08-reports/01-validation/10-recommendation-second-diversity-shadow-2026-08-10.md)에 기록한다.

## 완료 조건

- 앱 결과 화면에서 검토 창 진입 가능
- 앱 재시작 후 미완료 장면부터 이어서 검토
- 큰 이미지 비교와 기존 전체 화면 뷰어 연결
- 사람 1·2순위와 실패 이유의 원자적 저장
- 개인 큐 권한과 Git 제외 원칙 검증
- 자동추천 대비 집계가 사진 식별자 없이 생성됨
- 고정 shadow 후보와 교차검증 결과가 비식별 집계로 재현됨
- 승격 조건 미달 시 운영 점수가 유지됨
- 두 번째 추천 다양성 후보도 품질·표본 조건을 분리해 판정함
- AppKit 및 전체 자동 회귀와 설치 앱 검증 통과
