# 검증 보고서

`reports`는 특정 날짜와 환경에서 실행한 결과를 보관한다. 일반 사용법이나 미래 계획을 기록하는 곳이 아니다.

## 분류

- [실행 검증](01-validation/README.md): 앱, MCP, 권한, 실제 사진 흐름의 검증 결과
- [벤치마크](02-benchmarks/README.md): 모델, 처리량, 메모리, 품질 비교 결과

새 보고서에는 다음을 포함한다.

1. 날짜와 git revision
2. Mac·Linux 하드웨어와 OS
3. 앱·모델 정식 명칭
4. 입력 데이터의 수와 개인정보 처리 방식
5. 실행 명령 또는 재현 절차
6. 성공·실패·제외 기준
7. 원본 산출물 경로
8. 결론과 남은 위험

과거 숫자를 새 실행처럼 복사하지 않는다. 원본 산출물이 없으면 측정 결과로 간주하지 않는다.
