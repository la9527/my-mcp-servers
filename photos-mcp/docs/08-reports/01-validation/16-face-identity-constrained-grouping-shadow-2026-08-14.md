# 얼굴 동일인 constrained grouping shadow 검증

## 결론

고신뢰 SFace 연결로 익명 인물 core를 먼저 만들고, 중간 유사도 얼굴은 제한된 조건에서만 core에 부착하는 shadow를 구현했다.

- 복수 지지 정책은 core-only에서 끊긴 사진 연결 162개 중 92개를 복원했다.
- 기존 `0.363` grouping에 없던 사진 연결은 추가하지 않았다.
- 상호 최근접까지 허용하면 106개를 복원하지만 단일 연결 병합 38건이 추가된다.
- 복수 지지 정책은 다음 private audit 후보로 유지한다.
- 상호 최근접 정책은 사람 확인 전에는 사용하지 않는다.
- 추천 순위, 장면 grouping과 운영 데이터는 변경하지 않았다.

## 정책

### 공통 core

| 항목 | 값 |
| --- | ---: |
| core 동일인 후보 | `similarity >= 0.725` |
| 중간 부착 후보 | `similarity >= 0.363` |
| 강한 부착 근거 | 후보 중 하나 이상 `>= 0.55` |
| 동일 사진 얼굴 병합 | 항상 금지 |
| 주요 얼굴 필터 | 사진 내 최대 얼굴 면적의 50% 이상 |

### 복수 지지

서로 다른 component 사이에서 중간 유사도 연결이 2개 이상이고, 그중 하나 이상이 `0.55` 이상일 때만 부착한다. 한 개의 애매한 연결은 자동 확정하지 않는다.

### 상호 최근접 비교 후보

복수 지지 정책에 더해 다음 조건을 모두 통과한 singleton 얼굴만 연결한다.

1. 두 얼굴이 서로의 최근접 후보다.
2. 유사도가 `0.55` 이상이다.
3. 두 번째 후보와의 유사도 차이가 `0.05` 이상이다.
4. 촬영 시각 차이가 5분 이하다.

## 실제 116개 장면 결과

기존 1,000장 작업의 사람 검토 완료 장면과 314장·986개 얼굴 계측 캐시를 재사용했다.

| 정책 | 분리 장면 | 익명 인물 그룹 | 동일 그룹 사진 연결 |
| --- | ---: | ---: | ---: |
| 기존 단일 `0.363` | 53 | 182 | 325 |
| 고신뢰 core-only `0.725` | 74 | 227 | 163 |
| core + 복수 지지 | 71 | 216 | 255 |
| core + 복수 지지 + 상호 최근접 | 61 | 202 | 269 |

## 해석

복수 지지는 30회 component 병합 후보로 사진 단위 연결 92개를 복원했다. 여러 장에 반복 등장하는 동일인 core를 활용하므로 한 쌍만 보고 합치는 것보다 안전하다. 다만 기존 `0.363` 결과에 포함된 연결만 복원했다는 사실은 정확성을 증명하지 않는다. 기존 결과 자체에 오연결이 있을 수 있으므로 private audit이 필요하다.

상호 최근접 정책은 장면 분리 수를 77개에서 64개로 크게 낮추지만, 복수 근거 없이 39개 singleton을 연결한다. 직접 얼굴 pair 라벨에서 중간 유사도에 다른 사람 사례가 존재했으므로 자동 승격하지 않는다.

## 판정

| 후보 | 판정 | 다음 조건 |
| --- | --- | --- |
| core-only | 장면 적용 기각 | 동일인 재현율 부족 |
| core + 복수 지지 | private audit 진행 | 판독 가능한 17개 병합의 동일인 확인 |
| 상호 최근접 추가 | 보류 | 38개 병합 별도 확인 필요 |
| 운영 추천 반영 | 금지 | 독립 holdout·장면 audit 미완료 |
