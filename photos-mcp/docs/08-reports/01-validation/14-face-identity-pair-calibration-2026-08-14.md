# 얼굴 crop pair 직접 보정 검증

## 결론

전체 사진의 인물 구성을 라벨링하던 방식을 얼굴 crop 두 개의 동일인 여부를 직접 판단하는 방식으로 교체했다. 기존 장면 단위 `63.06%`는 얼굴 정확도가 아닌 장면 유지율로 재분류했으며, 새 얼굴 pair 라벨이 쌓이기 전에는 SFace 기준값을 운영에 반영하지 않는다.

## 검토 UX

현재 UX 점수는 구현 전 `4/10`에서 구현 기준 `9/10`으로 개선했다. 기존 화면은 전체 사진의 배경·행인·검출 누락을 사용자가 동시에 해석해야 하는 심각도 4 문제가 있었다. 새 화면은 한 번에 얼굴 두 개와 네 개의 명확한 판단만 제공한다.

| 키 | 라벨 | 보정 처리 |
| --- | --- | --- |
| `1` | 같은 사람 | positive pair |
| `2` | 다른 사람 | negative pair |
| `3` | 판단 어려움 | 임계값 계산 제외 |
| `4` | 잘못 검출 | 임계값 계산 제외, 검출 실패 집계 |

얼굴 similarity와 표본 난이도는 화면에 노출하지 않는다. 좌우 화살표로 이전·다음 쌍을 이동할 수 있고, 원본은 `원본 사진 보기`를 선택할 때만 연다. 클릭 또는 숫자 키 입력은 즉시 개인 큐에 저장된다.

## 데이터 계약

개인 큐는 다음 경로에만 저장한다.

```text
~/.photos-mcp/validation/face-identity/<job-id>/
├── review-private.json
└── crops/
```

큐와 crop 디렉터리는 각각 `0600`, `0700` 권한을 사용한다. Git 보고서에는 사진 ID, 경로, bbox, 얼굴 crop, embedding과 pair similarity를 포함하지 않는다.

## 보정 지표

`scripts/analyze_face_identity_calibration.py`는 라벨된 정확한 얼굴 쌍의 cosine만 사용한다.

| 지표 | 승격 기준 |
| --- | ---: |
| 같은 사람 표본 | 100쌍 이상 |
| 다른 사람 표본 | 100쌍 이상 |
| 같은 사람 재현율 | 90% 이상 |
| 다른 사람 false match rate | 5% 이하 |

표본 수와 품질 기준을 모두 통과한 경우에만 `recommended_candidate`와 `promotion_ready: true`를 반환한다.

## 240쌍 라벨 완료 결과

사용자가 전체 240쌍 검토를 완료한 뒤 보정기를 다시 실행했다.

| 라벨 | 결과 |
| --- | ---: |
| 같은 사람 | 88쌍 |
| 다른 사람 | 138쌍 |
| 잘못 검출 | 14쌍 |
| 판단 어려움 | 0쌍 |
| 보정 사용 가능 | 226쌍 |

같은 사람 표본은 목표 100쌍에 12쌍 부족했다. 표본 수와 별개로 단일 threshold의 분리 성능도 승격 기준을 통과하지 못했다.

| 구간 | 같은 사람 | 다른 사람 | 잘못 검출 |
| --- | ---: | ---: | ---: |
| 고유사도 | 65 | 0 | 7 |
| 임계값 주변 | 23 | 61 | 0 |
| 동일 사진 내 얼굴 | 0 | 47 | 1 |
| 저유사도 | 0 | 30 | 6 |

고유사도와 저유사도 구간은 명확히 분리됐지만 임계값 주변에서 두 클래스가 겹쳤다. threshold `0.35`에서는 동일인을 놓치지 않았지만 다른 사람의 `57.25%`를 동일인으로 잘못 연결했다. 반대로 관찰 최고점인 `0.725`는 다른 사람 오연결이 없었지만 동일인 재현율이 `73.86%`에 그쳤다.

따라서 `recommended_candidate: null`, `sample_ready: false`, `promotion_ready: false`가 최종 결과다. 현재 SFace cosine 하나에 단일 threshold를 적용하는 방식은 운영에 반영하지 않는다.

## 확정 후속 방향

1. `>= 0.725`는 보수적 동일인 연결 후보로, `<= 0.35`는 보수적 다른 사람 후보로 분리한다.
2. `0.35 < similarity < 0.725`는 자동 확정하지 않고 보조 특징 또는 사용자 검토 대상으로 남긴다.
3. 동일인 12쌍 이상을 추가 확보하되 경계 표본만 반복 수집하지 않고 연령·표정·측면 얼굴을 균형 있게 포함한다.
4. 얼굴 품질, 연령 차이, 촬영 시기와 인접 장면 정보를 결합한 이중 threshold shadow를 1,000장에 재생한다.
5. 기존 추천 순위에는 아직 영향을 주지 않고 익명 인물 집합의 정밀도와 커버리지를 먼저 검증한다.
