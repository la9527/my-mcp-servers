# 얼굴 동일인 이중 임계값 shadow 검증

## 결론

SFace cosine 하나를 단일 임계값으로 확정하는 방식 대신 다음 세 구간을 shadow로 재생했다.

| 구간 | 판정 |
| --- | --- |
| `similarity <= 0.35` | 보수적 다른 사람 후보 |
| `0.35 < similarity < 0.725` | 자동 판정 보류 |
| `similarity >= 0.725` | 보수적 같은 사람 후보 |

완료된 직접 얼굴 pair 라벨에서는 자동 판정 124쌍 모두 정답이었다. 그러나 `0.725` 연결만으로 장면별 익명 인물 그룹을 만들면 28개 장면이 추가 분리됐다. 따라서 pair triage는 후속 shadow에 사용할 수 있지만, 장면 그룹 생성에 직접 적용하는 방식은 과분리 위험으로 기각한다.

기존 추천 순위, 장면 그룹, 내보내기와 운영 데이터는 변경하지 않았다.

## 구현

- `face_identity_triage.py`: 이중 임계값 판정, 자동 처리율, 오류율과 Wilson 95% 상한 계산
- `analyze_face_identity_triage_shadow.py`: 개인 얼굴 라벨과 기존 장면 계측을 연결하는 비식별 재생 CLI
- 중간 유사도는 강제 결정하지 않고 `deferred`로 유지
- 동일 데이터에서 고른 임계값은 운영 승격에 사용하지 않고 독립 holdout을 요구
- 출력에는 사진 ID, 경로, 얼굴 crop, 장면 ID와 embedding을 포함하지 않음

## 얼굴 pair 결과

잘못 검출 14쌍을 제외한 유효 라벨 226쌍을 사용했다.

| 항목 | 결과 |
| --- | ---: |
| 같은 사람 | 88쌍 |
| 다른 사람 | 138쌍 |
| 자동 같은 사람 | 65쌍 |
| 자동 다른 사람 | 59쌍 |
| 보류 | 102쌍 |
| 자동 처리율 | 54.87% |
| 자동 판정 정확도 | 100% |
| 관측 false match | 0 / 138 |
| false match Wilson 95% 상한 | 2.71% |
| 관측 false split | 0 / 88 |
| false split Wilson 95% 상한 | 4.18% |

직접 라벨 표본 안에서는 오류 상한 5%와 자동 처리율 50% 기준을 통과해 `shadow_ready: true`다. 다만 같은 표본에서 임계값을 정하고 평가했으므로 `independent_holdout_required: true`, `promotion_ready: false`를 유지한다.

## 116개 장면 재생

기존 1,000장 작업에서 사람 검토를 완료한 116개 장면과 314장 계측 캐시를 재사용했다.

| 항목 | 기존 `0.363` | 보수적 `0.725` |
| --- | ---: | ---: |
| 분리된 장면 | 56 | 77 |
| 익명 인물 그룹 | 185 | 230 |
| 얼굴이 없는 장면 | 4 | 4 |

| 변경 영향 | 결과 |
| --- | ---: |
| 그룹 구성이 바뀐 장면 | 28 |
| 그룹 수가 증가한 장면 | 28 |
| 그룹 수가 감소한 장면 | 0 |
| 기존 동일 그룹 연결 제거 | 162 |
| 새로운 동일 그룹 연결 추가 | 0 |

보수적 같은 사람 연결은 오연결을 줄이는 대신 동일인을 놓쳐 장면을 잘게 나눈다. 직접 라벨에서도 동일인 자동 연결 재현율이 73.86%였으므로 장면 결과와 방향이 일치한다.

## 판정

| 적용 영역 | 판정 | 이유 |
| --- | --- | --- |
| 얼굴 pair 자동 triage | shadow 진행 | 54.87% 자동 처리, 관측 오류 0건 |
| 중간 구간 자동 확정 | 기각 | 같은 사람과 다른 사람이 겹침 |
| `0.725` 단독 장면 grouping | 기각 | 28개 장면 추가 분리, 연결 162개 제거 |
| 운영 추천 순위 반영 | 보류 | 독립 holdout과 과분리 보완 미완료 |

## 다음 실험

1. `>= 0.725` 얼굴 연결로 정밀한 익명 인물 core만 만든다.
2. 중간 구간 얼굴은 한 개의 cosine으로 합치지 않는다.
3. 같은 core와의 복수 연결, 촬영 시기, 같은 장면의 인물 공존 제약을 이용해 보조 부착한다.
4. 부착하지 못한 얼굴은 `unknown`으로 유지해 과분리와 오연결을 모두 측정한다.
5. 현재 240쌍과 겹치지 않는 독립 holdout 얼굴 pair를 구성해 재검증한다.
6. 운영 반영 전 1,000장 추천 Top-1·Top-2와 내보내기 회귀를 다시 실행한다.
