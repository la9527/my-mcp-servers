# Apple Photos 이름 후보의 다중 얼굴 복구 검증

## 결론

Apple Photos 이름 후보 사진을 열었을 때 `사진 속 얼굴 0개`로 표시되던 문제를 수정했다. 문제 사진에는 실제로 두 사람이 있었고 모델 파일도 정상이었다. 원인은 3648px 원본 전체를 YuNet에 그대로 입력해 검출 문맥이 불안정해진 것과, 자동 검토 큐의 `quality_suppressed` 필터를 사용자가 명시적으로 연 이름 후보 화면에도 재사용한 것이었다.

검출은 최대 긴 변 1600px인 분석용 이미지에서 수행하고, 얼굴 상자와 5개 landmark를 원본 좌표로 복원한 뒤 원본 픽셀로 정렬 crop·embedding·geometry를 생성하도록 변경했다. 기존 사용자 확정 얼굴 연결은 재분석에서도 보존한다.

## 화면과 데이터 경계

- 일반 `빠르게 확인` 큐는 계속 예외 중심 정책을 사용한다. 품질이 낮고 자동 처리가 불필요한 얼굴은 노출하지 않는다.
- Apple Photos 이름 후보 상세 화면은 별도 `provider_alias_review_detail` projection을 사용한다.
- 해당 사진에서 검출된 미확정 얼굴 crop은 자동 품질 억제 여부와 무관하게 이름 연결 후보로 볼 수 있다.
- 사용자가 직접 `모르는 사람 · 무시`, `얼굴 아님`, 확정 연결을 수행한 항목은 다시 후보로 나타나지 않는다.
- 전체 사진에는 얼굴 번호와 사각형을 표시하고, 아래 crop의 `얼굴 1`, `얼굴 2` 순서와 일치시킨다.
- 기존 확정 인물 추천 이름이 Apple Photos 이름 힌트의 끝부분과 유일하게 일치하면 해당 얼굴을 미리 선택한다. 이름 원문은 UI와 private DB 안에서만 처리한다.
- 복구 동작은 `이 사진 얼굴 다시 찾기` 한 개의 주 동작으로 제공한다. 실행 중, 완료, 실패 상태를 같은 화면에 표시한다.

## 안전한 재분석 정책

새 검출 결과와 crop·embedding·geometry·미리보기 저장이 성공한 뒤에만 같은 모델의 이전 미확정 검출을 `missing`으로 전환한다. 다음 항목은 보존한다.

- 사용자가 직접 확정한 얼굴 membership
- 다른 사진의 얼굴 관측
- 감사 기록과 과거 revision

따라서 검출 실패 중간 상태가 기존 결과를 지우지 않으며, 개선된 검출이 성공했을 때만 잘못된 얼굴 조각이 활성 목록에서 사라진다.

## Mac과 Android 연결

- Mac 인물 관리 상세는 이름 후보 전용 얼굴 projection과 번호가 표시된 전체 사진을 사용한다.
- Android의 기존 `빠르게 인물 확인` 화면은 이미 사진별 다중 crop, 얼굴별 이름 연결, 전체 사진 전환을 지원한다.
- 모바일 얼굴 검토 API가 대기 중인 Apple Photos 이름 후보 사진도 같은 face-level 응답에 포함하므로 Android에서도 같은 두 얼굴을 선택할 수 있다.
- API는 내부 asset id, face id, 파일 경로를 노출하지 않고 기존의 기기별 opaque handle과 인증된 이미지 URL을 유지한다.

## 실제 운영 사진 검증

대상: Apple Photos 이름 후보가 두 개 연결된 운영 사진 1장. 개인 이름과 내부 사진 식별자는 보고서에 기록하지 않는다.

| 항목 | 결과 |
| --- | --- |
| 입력 원본 | 3648 × 2736 |
| 기존 활성 검출 | 얼굴 조각 2개 + 낮은 신뢰도 얼굴 1개, UI 선택 0개 |
| 수정 후 검출 | 정확한 얼굴 2개 |
| 성인 얼굴 | `review_eligible`, 기존 확정 인물 후보 1명, 일치 가능성 80.6% |
| 아이 얼굴 | `auto_eligible`, 기존 확정 인물 후보 1명, 일치 가능성 96.7% |
| 번호 미리보기 | 얼굴 1 성인, 얼굴 2 아이, crop 순서와 일치 |
| 실패 수 | 0 |

운영 재분석 run은 성공 상태로 private 인물 저장소에 보존했다.

## 사용자 동선

1. `인물 관리`에서 `빠르게 확인`을 누른다.
2. Apple Photos 이름 후보의 전체 사진에서 번호를 확인한다.
3. 미리 선택된 얼굴이 맞으면 기존 인물 연결 또는 새 인물 등록을 수행한다.
4. 얼굴이 없거나 잘못 분리된 경우 `이 사진 얼굴 다시 찾기`를 누른다.
5. 다른 얼굴은 각각 별도로 연결하거나 모르는 사람으로 무시한다.
