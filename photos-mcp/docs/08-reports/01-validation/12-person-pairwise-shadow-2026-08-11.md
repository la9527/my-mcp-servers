# 동일 인물 사진 pairwise VLM shadow 검증

## 결론

동일 인물 구성 후보를 두 장씩 직접 비교하는 VLM 방식은 개선 가능성을 보였지만 운영 승격 조건을 통과하지 못했다. 단일 요청은 마지막에 제시된 사진 B를 선호하는 위치 편향이 매우 컸다. A/B 순서를 뒤집은 두 요청이 같은 실제 사진을 선택할 때만 인정하는 mirror-consensus는 오류를 줄였지만 32쌍 중 21쌍을 보류했고 잔여 위치 격차도 컸다.

운영 `scene_selection`과 추천 점수는 변경하지 않는다. pairwise 판단은 계속 shadow로 유지한다.

## 시험 구성

| 항목 | 값 |
| --- | --- |
| 원본 작업 | 실제 로컬 사진 1,000장 작업 `f5d85ba2` |
| 사람 검토 기준선 | 완료 장면 116개 |
| pairwise 표본 | 32쌍 |
| 표본 구성 | 현재 1위 정답 16쌍, 현재 1위 오답 16쌍 |
| 인물 구성 | SFace cosine `0.45`, 동일 익명 인물 그룹 |
| 모델 | Linux `Qwen3.6-35B-A3B-Q4_K_M.gguf` |
| 요청 | 정방향 32회 + A/B 역방향 32회 |
| 입력 | 1024px 미리보기 두 장 |
| 프롬프트 | `person-pairwise-shadow-v1` |

사용자 선택은 평가 정답과 경쟁 후보 구성에만 사용했다. A/B 위치는 case hash로 결정해 한쪽에 몰리지 않게 했으며 공개 집계에는 사진 ID, 경로와 모델의 자연어 설명을 포함하지 않았다.

## Mirror-consensus 결과

정방향과 역방향 응답을 실제 사진 기준으로 다시 맞췄다. 두 응답이 같은 사진을 고른 경우만 선택하고, 불일치는 tie로 처리해 기존 추천을 유지했다.

| 지표 | 결과 |
| --- | ---: |
| 기존 기준선 일치율 | 50.00% |
| consensus 적용 일치율 | 68.75% |
| 기준선 대비 | +18.75%p |
| 기존 오답 회복 | 7쌍 |
| 기존 정답 악화 | 1쌍 |
| 판단 보류 | 21쌍 |
| 양쪽 순서에서 합의한 선택 | 11쌍 |
| 합의 선택의 사람 일치 | 9/11, 81.82% |
| A/B 위치 격차 | 33.73%p |

합의된 사례는 비교적 정확했지만 적용 범위가 34.38%에 불과하고 위치 격차가 사전 기준 10%p를 넘었다. 자동 추천을 바꿀 만큼 안정적이지 않다.

## 시각 점검

합의했지만 사람 선택과 달랐던 2쌍을 직접 확인했다.

- 한 쌍은 모델이 얼굴이 더 정면인 사진을 선택했지만 사용자는 인물이 더 크게 배치된 순간과 구도를 선택했다.
- 다른 쌍은 주요 인물 중 한 명의 눈 상태가 좋지 않은 사진을 모델이 선택해 명확한 얼굴 결함도 완전히 제거하지 못했다.

전체 프레임만 축소해 입력하면 작은 얼굴 상태가 충분히 전달되지 않고, 모델이 표정과 구도 중 무엇을 우선할지도 장면에 따라 달라진다.

## 얼굴 crop 보드 재시험

전체 프레임 축소에서 작은 얼굴 상태가 충분히 보이지 않는 문제를 확인해, 각 후보의 전체 사진과 최대 네 개의 주요 얼굴 crop을 하나의 768px 보드로 합쳐 같은 32쌍을 다시 비교했다. 배경 행인은 기존 주요 얼굴 면적 필터로 제외했다.

| 지표 | 전체 프레임 v1 | 얼굴 crop 보드 v3 |
| --- | ---: | ---: |
| 단일 요청 일치율 | 59.38% | 59.38% |
| 단일 요청 위치 격차 | 63.92%p | 63.92%p |
| mirror-consensus 일치율 | 68.75% | 68.75% |
| mirror 합의 선택 수 | 11 / 32 | 13 / 32 |
| 합의 선택의 사람 일치 | 81.82% | 69.23% |
| mirror 위치 격차 | 33.73%p | 33.73%p |

얼굴 crop을 넣어도 마지막에 제시된 B 후보 선호가 사라지지 않았다. 합의 사례 수는 두 건 늘었지만 합의 사례의 사람 선택 일치가 낮아져 개선 근거가 되지 못했다. 후보 입력 개선만으로 위치 편향을 해결할 수 없으므로 pairwise VLM은 운영 승격하지 않는다.

## 판정과 다음 단계

| 후보 | 판정 | 이유 |
| --- | --- | --- |
| 단일 pairwise 요청 | 기각 | 마지막 이미지 위치 편향 63.92%p |
| mirror-consensus | shadow 유지 | 정확도 개선 가능성은 있으나 21/32 보류, 위치 격차 33.73%p |
| 운영 추천 | 유지 | 승격 기준 미충족 |

다음 단계는 VLM 대결이 아니라 사람 검토 기반의 인물 구성 보정이다. `인물 구성 검토`에서 최소 `같은 주요 인물` 30장면과 `다른 주요 인물` 30장면을 라벨링하고, SFace cosine 및 주요 얼굴 면적 기준을 교차 평가한다. 동일 실제 사진을 양쪽 순서에서 선택한 경우만 후보 보조 신호로 사용하는 pairwise 승격은 최소 30개 결정 사례와 위치 격차 10%p 이하를 충족할 때까지 보류한다.

## 재현

```bash

  --review ~/.photos-mcp/validation/recommendation-quality/f5d85ba2/review-private.json \
  --database ~/.photos-mcp/runtime/photo-ranker/jobs.db \
  --measurements ~/.photos-mcp/validation/person-aware-scene-shadow/f5d85ba2/measurements-private.json \
  --private-root ~/.photos-mcp/validation/person-aware-scene-shadow/f5d85ba2 \
  --output /tmp/photos-mcp-person-pairwise-shadow-summary.json \
  --max-cases 32
```
