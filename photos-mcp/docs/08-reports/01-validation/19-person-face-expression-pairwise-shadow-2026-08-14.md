# 동일 주 피사체 얼굴·표정 순위 shadow 검증

## 결론

사람이 `same_primary_subjects`로 확인한 91개 장면에서 얼굴·표정 순위를 다시 검증했다. 얼굴 신호가 두 사진 이상에서 측정된 87개 장면이 최종 비교 대상이었다.

얼굴 품질과 표정을 전체 순위에 직접 반영하거나 작은 보너스로 더하는 정책은 모두 기존 순위보다 낮았다. 가장 보수적인 `strict` 결함 veto만 한 장면을 올바르게 바꿔 Top-1 일치율을 `74.71%`에서 `75.86%`로 높였지만, 변경 표본이 한 건뿐이라 운영 승격 근거로는 부족하다.

운영 `scene_selection`과 추천 점수는 변경하지 않는다. `strict` veto는 독립 holdout에서 추가 사례를 확보할 때까지 shadow 후보로만 유지한다.

## 평가 설계

기존 실험은 SFace 임계값으로 자동 생성한 동일 인물 그룹 안에서 순위를 비교했다. 이번 실험은 자동 그룹 오류가 순위 평가에 섞이지 않도록 사람이 직접 지정한 장면 라벨을 우선했다.

| 항목 | 값 |
| --- | ---: |
| 사람 검토 완료 장면 | 116개 |
| 동일 주 피사체 확인 장면 | 91개 |
| 얼굴 신호 비교 가능 장면 | 87개 |
| 계측 사진 | 314장 |
| 얼굴 검출 사진 | 302장 |
| 얼굴 관측 | 986개 |
| 표정 신호 사진 | 283장 |

사람의 복수 1순위 라벨이 있을 때는 후보 Top-1이 그중 하나이면 일치로 계산했다. 결과 파일에는 사진 ID, 경로, 얼굴 box와 임베딩을 저장하지 않았다.

## 결과

| 정책 | Top-1 일치 | 변경 | 개선 | 악화 | 순 개선 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 운영 순위 | 74.71% | 0 | 0 | 0 | 0 |
| 얼굴 주도 순위 | 54.02% | 36 | 7 | 25 | -18 |
| 얼굴 보너스 0.05점 | 73.56% | 1 | 0 | 1 | -1 |
| 얼굴 보너스 0.10점 | 71.26% | 4 | 0 | 3 | -3 |
| 얼굴 보너스 0.20점 | 70.11% | 7 | 1 | 5 | -4 |
| 얼굴 보너스 0.50점 | 68.97% | 10 | 2 | 7 | -5 |
| 얼굴 보너스 1.00점 | 66.67% | 16 | 4 | 11 | -7 |
| strict 결함 veto | **75.86%** | 1 | 1 | 0 | **+1** |
| conservative 결함 veto | 73.56% | 1 | 0 | 1 | -1 |
| balanced 결함 veto | 72.41% | 2 | 0 | 2 | -2 |

`strict` 교체 사유는 얼굴 crop 선명도 한 건이었다. `conservative`와 `balanced`는 눈 뜸 신호로 변경했지만 사람 선택을 악화시켰다. 미소, 시선과 얼굴 촬영 품질을 가산하는 방식은 사진의 전체 순간과 구도 의도를 대체하지 못한다는 기존 결과가 다시 확인됐다.

## 동일인 교차 확인

고신뢰 core와 복수 지지를 사용하는 `core-multi-support` 정책으로 자동 동일인 구성을 교차 확인했다.

| 상태 | 장면 |
| --- | ---: |
| 모든 사진의 익명 인물 구성이 일치 | 37개 |
| 분리 또는 판정 보류 | 50개 |

자동 그룹 결과는 평가 필터로 사용하지 않았다. 현재 정책은 오병합을 줄이기 위해 의도적으로 보수적이고, 독립 holdout의 사람 라벨도 완료되지 않았기 때문이다. 50개는 다른 사람이라는 뜻이 아니라 검출 누락, singleton 보류 또는 구성 분리를 포함한다.

## 판정

| 후보 | 판정 | 이유 |
| --- | --- | --- |
| 얼굴 주도 순위 | 기각 | 기존 대비 20.69%p 하락 |
| 얼굴 점수 보너스 | 기각 | 모든 보너스에서 순 악화 |
| conservative·balanced veto | 기각 | 눈 신호 교체가 사람 선택을 악화 |
| strict veto | shadow 유지 | 순 개선 +1건이지만 변경 표본 1건 |
| 기존 운영 순위 | 유지 | 현재 가장 안정적인 검증 기준선 |

`strict` veto를 승격하려면 독립 데이터에서 결함 교체 사례가 최소 20건 이상 관측되고, 악화 없이 순 개선이 재현되어야 한다. 같은 91개 장면에서 임계값을 더 조정하지 않는다.
