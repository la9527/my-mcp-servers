# 500장 결과 표시와 상대 추천 기준 검증

## 목적

로컬 사진 500장 분류 완료 작업에서 결과 창이 100장만 표시하던 문제와, 일반 분류의 추천이 절대 점수 80점에 묶여 0건으로 보이던 문제를 확인하고 수정했다.

## 변경

- 결과 조회 API의 `result_count`를 전송된 일부 항목 수가 아닌 완료 결과 전체 수로 반환한다.
- 결과 창은 직접 분류의 제품 상한인 1,000장까지 한 번에 불러온다.
- 일반 `사진 분류`는 다중 사진 장면에서 상대 순위 1위와 조건을 통과한 2위를 추천한다.
- `우수 사진 선별`은 기존 전체 품질 백분위 기준을 계속 사용한다.
- 이전 완료 작업은 저장된 장면 그룹·순위를 사용해 다시 VLM을 실행하지 않고 새 추천 정책으로 보정한다.

## 실제 완료 작업 재검증

개인 원본 경로나 사진 식별자는 기록하지 않았다.

| 항목 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 완료 결과 | 500장 | 500장 |
| 결과 창 로드 | 100장 | 500장 |
| 다중 사진 장면 | 49개 | 49개 |
| 추천 | 0장 | 98장 |
| 장면별 추천 슬롯 | 없음 | 1위 49장, 2위 49장 |
| 재분석 | 해당 없음 | 실행하지 않음 |

보정은 기존 결과 DB의 장면 그룹, 그룹 크기, 그룹 내 순위만 사용했다. 따라서 VLM 재호출이나 원본 파일 수정 없이 결과 표시와 내보내기 후보가 동일한 추천 정책을 따르게 된다.

## 자동 검증

```bash
./.venv/bin/pytest -q
```

결과: 437 passed, 5.34초.

추가로 실제 완료 작업의 결과 조회에서 전체 500장과 로드 500장, 상대 추천 정책, 추천 98장을 확인했다.

## 남은 주의점

- 이전 작업 보정은 과거에 저장한 장면 순위를 사용하므로, 새 작업의 시각적 다양성 검사만큼 정교하게 2순위를 걸러내지는 못한다.
- 새 작업은 시각 특징 거리와 점수 차이를 함께 적용해 거의 같은 연속 사진을 2순위 추천에서 제외한다.
