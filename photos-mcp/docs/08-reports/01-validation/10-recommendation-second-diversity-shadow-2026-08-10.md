# 두 번째 추천 시각적 다양성 shadow 검증

## 결론

두 번째 추천 임계값은 변경하지 않는다. `Vision 0.008 + pHash 0.08` 후보가 현재 남아 있는 명시적 중복 추천 1건을 제거하면서 Top-2 포함률 손실을 0.86%로 제한했지만, 중복 라벨이 4개뿐이라 승격에 필요한 최소 20개를 충족하지 못했다.

판정은 `insufficient_labels`이며 후보는 shadow 상태로 유지한다.

## 기준선 재생

사람 검토를 완료한 116장면의 미리보기 314장을 로컬에서 다시 계측했다. 원격 LLM은 호출하지 않았고 macOS Apple Vision FeaturePrint와 pHash만 사용했다.

| 항목 | 결과 |
| --- | ---: |
| 완료 장면 | 116개 |
| 분석 미리보기 | 314장 |
| 미리보기 누락 | 0장 |
| 현재 두 번째 추천 | 105개 |
| 명시적 중복 장면 | 4개 |
| 중복인데 두 번째 추천이 남은 장면 | 1개 |
| 사용자 1순위 Top-2 포함률 | 93.10% |
| 사용자 2순위 | 1개, 현재 추천에 포함 |
| 저장 결과와 현재 정책 재생 불일치 | 0개 |

중복 표시 4개 중 3개는 현재 Vision `0.008` 조건이 이미 두 번째 추천을 막고 있었다. 실제 개선 대상은 두 번째 추천이 남은 1개 장면이다.

## 승격 조건

다음 조건을 모두 만족해야 운영 정책으로 승격한다.

1. 명시적 중복 라벨이 최소 20개다.
2. 현재보다 중복 두 번째 추천을 실제로 줄인다.
3. 중복 라벨 장면에서 두 번째 추천 잔여가 0개다.
4. 사용자 1순위 Top-2 포함률 손실이 1% 이내다.
5. 사용자가 고른 2순위를 모두 유지한다.
6. Apple Vision FeaturePrint를 사용하고 미리보기 누락이 없다.
7. 현재 정책 재생이 저장된 추천과 모든 장면에서 일치한다.

`Vision 0.008 + pHash 0.08`은 품질 조건은 통과했지만 표본 조건은 통과하지 못했다. 현재 4개 라벨에서 20개까지 최소 16개가 더 필요하다.

## 재현

```bash
PYTHONPATH=src .venv/bin/python scripts/analyze_recommendation_diversity.py \
  --review ~/.photos-mcp/validation/recommendation-quality/<job-id>/review-private.json \
  --database ~/.photos-mcp/runtime/photo-ranker/jobs.db \
  --output /tmp/photos-mcp-recommendation-diversity-summary.json
```

입력은 개인 사진 ID와 경로를 포함하지만 출력은 장면 수, 임계값별 집계와 승격 판정만 포함한다. 원본과 미리보기는 복사하거나 수정하지 않는다.
