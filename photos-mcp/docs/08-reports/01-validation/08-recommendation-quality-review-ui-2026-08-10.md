# 추천 품질 사람 검토 UI 검증

## 범위

리팩터링 후 첫 후속 단계로 현재 자동추천과 사용자의 실제 선택을 비교하는 장면별 검토 기능을 추가했다. 검토는 분류 결과와 사진 원본을 변경하지 않으며 개인 큐에만 저장한다.

## 구현 결과

| 항목 | 결과 |
| --- | --- |
| 진입점 | 결과 갤러리 하단 `추천 품질 검토` 버튼 |
| 검토 단위 | 복수 사진이 있는 장면 군집 |
| 사람 선택 | 장면별 1순위 필수, 2순위 선택 |
| 상세 확인 | 기존 전체 화면 사진 뷰어 연결 |
| 추가 라벨 | 장면 경계와 눈 감김·흐림·표정·중복·기타 오류 |
| 저장 | 선택마다 원자적 JSON 교체, 앱 재시작 후 이어서 검토 |
| 개인정보 | `~/.photos-mcp` 개인 경로, 디렉터리 `0700`, 파일 `0600` |
| 집계 | 자동 1순위 적중률, Top-2 포함률, 사람 선택 재현율, 자동추천 정밀도 |

Computer Use로 설치 앱의 1,000장 결과를 열어 버튼 노출, 140장면 표시, 자동추천 1·2순위 배지, 두 열 큰 이미지, 사람 1·2순위 선택, 저장 후 다음 장면 이동과 실시간 집계 갱신을 확인했다. 검증용 선택은 종료 전에 백업으로 복원해 실제 사용자 ground truth에는 포함하지 않았다.

## 후속 판정

사용자가 116개 장면 검토를 완료해 최소 조건을 충족했다. 기준선과 shadow 비교 결과는 [추천 품질 사람 기준선 및 shadow 점수 검증](09-recommendation-shadow-score-2026-08-10.md)에 기록했다. 현재 점수 필드의 재가중치는 Top-1을 개선하지 못해 운영 순위를 유지한다.
