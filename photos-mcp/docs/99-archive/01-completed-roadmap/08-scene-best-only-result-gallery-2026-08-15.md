# 장면 대표 한 장 결과 갤러리

## 목표

같은 장면으로 묶인 여러 추천 사진을 메인 결과 격자에 반복 노출하지 않는다. 장면별로 가장 높은 점수의 대표 사진 한 장만 먼저 보여주고, 나머지 사진은 필요할 때 별도 비교 화면에서 확인한다.

## 사용자 흐름

1. 결과 창은 기본적으로 `장면별` 보기를 연다.
2. 장면은 각 그룹의 대표 사진 종합 점수 내림차순으로 배치한다.
3. 각 카드에는 대표 사진, `BEST` 배지, 장면 전체 사진 수와 `같은 장면 대안 N장 보기`를 표시한다.
4. 대안 보기를 누르면 해당 장면 사진만 담은 `같은 장면 사진 비교` 확대 창을 연다.
5. 비교 창에서는 화살표 키와 확대 기능으로 사진을 비교한다. 자동 대표 순위는 변경하지 않는다.
6. 사용자가 모든 분석 결과를 점수순으로 보고 싶으면 `사진별` 보기로 전환한다.

## 구현 원칙

- `scene_cluster_id`를 기준으로 결과 표현 계층에서 그룹을 만든다.
- 그룹의 대표 사진과 그룹 내부 사진은 모두 동일한 점수 정렬 규칙을 사용한다.
- 추천·검토 필요 필터는 해당 분류에 속한 사진이 있는 장면만 보이고, 그 분류에서 점수가 가장 높은 사진을 대표로 보인다.
- 내보내기 선택은 기존처럼 개별 사진 단위로 유지하며, `추천 장면 베스트 선택`은 추천된 각 장면에서 최고 점수 1장을 선택하는 선택 프리셋으로 제공한다.
- 비교 창은 기존 원본 확대·RAW 미리보기·키보드 이동 기능을 재사용한다.
- 이 단계는 추천 점수 및 장면 clustering 알고리즘을 변경하지 않는 UI 개선이다.

## 검증

- 장면별 보기에서 한 장면당 한 카드만 노출되는지 확인한다.
- 장면 대표와 대안이 점수 내림차순인지 확인한다.
- 사진별 보기에서 기존 전체 결과 접근이 유지되는지 확인한다.
- 카드의 대안 보기, 선택, 내보내기와 우측 Inspector가 함께 동작하는지 AppKit 실화면에서 확인한다.

## 구현 및 검증 결과

- 2026-08-15에 장면별/사진별 전환, 대표 카드, 대안 보기와 기존 확대 뷰어 연결을 구현했다.
- 실제 Google Photos 결과 50장으로 장면별 대표 카드와 `같은 장면 대안 N장 보기`를 확인했다.
- 비교 창은 `1/3`, `2/3`처럼 점수 순위를 표시하고 좌우 화살표 키로 대안을 이동할 수 있음을 확인했다.
- 자동 테스트 전체 604건과 standalone 앱의 codesign, health, runtime import, vendor runtime smoke 검증을 통과했다.
- `추천 장면 베스트 선택`은 추천된 장면마다 한 장만 선택하고, 단일 사진 장면도 포함한다. 이 선택은 기존 수동 선택과 동일하게 영속화하며 Apple 사진 앨범, 로컬 폴더, Google Photos 새 앨범 내보내기에 그대로 사용한다.
