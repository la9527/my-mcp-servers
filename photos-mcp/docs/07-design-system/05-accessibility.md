# 접근성

## 키보드

| 키 | 동작 |
| --- | --- |
| 좌우 방향키 | 이전·다음 사진으로 포커스 이동 |
| Enter | 포커스 사진의 분류 대상 토글 |
| Space | Enter와 같은 분류 대상 토글 |
| Escape | modal 또는 사진 뷰어 닫기 |

키 입력은 text field 편집 중일 때 가로채지 않는다. 격자와 한 장 보기에서 같은 의미를 유지한다.

## VoiceOver

- 아이콘만 있는 control에는 `accessibilityLabel`과 tooltip을 지정한다.
- 사진 카드는 파일명, 분류 상태, 점수 순서로 읽을 수 있어야 한다.
- 체크 상태는 시각 이미지가 아니라 control value로도 노출한다.
- 진행률은 값이 바뀔 때 과도한 알림을 만들지 않는다.

## 대비와 상태

- secondary text도 배경에서 읽을 수 있는 대비를 유지한다.
- 녹색 점 하나로 정상 상태를 전달하지 않고 `서버 실행 중` 같은 텍스트를 병기한다.
- 경고와 오류는 아이콘, 제목, 해결 안내를 함께 제공한다.
- 선택 테두리는 accent color를 사용하되 키보드 focus와 구분한다.

## 클릭 영역

작은 SF Symbol을 사용해도 버튼 frame은 최소 32pt 이상을 목표로 한다. 사진 우측 상단 체크는 이미지 모서리에서 충분히 떨어뜨리고 배경 대비를 제공해 밝은 사진에서도 보이게 한다.

## 동작 감소

상태 갱신과 이미지 전환은 기능 이해에 필요한 정도로만 애니메이션을 사용한다. 시스템의 동작 감소 설정을 우회하는 지속 애니메이션을 추가하지 않는다.
