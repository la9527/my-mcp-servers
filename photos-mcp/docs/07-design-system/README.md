# AppKit 디자인 시스템

> 구현 기준: `src/photos_mcp/ui_theme.py`와 `*_appkit.py`

Photos MCP UI는 macOS의 창, 입력, 색상, SF Symbols, 접근성 동작을 우선한다. 별도 이미지 mockup은 방향 참고일 뿐이며 실제 화면의 기준은 공통 토큰과 창 크기별 레이아웃 검증이다.

## 문서 구성

- [기초 토큰](02-foundations.md): 글꼴, 간격, 색상, 크기
- [컴포넌트](03-components.md): 버튼, 카드, 목록, 선택 상태
- [화면 패턴](04-screen-patterns.md): 메인, 폴더 브라우저, 결과 갤러리, 뷰어
- [접근성](05-accessibility.md): 키보드, VoiceOver, 대비, 상태 전달

## 설계 원칙

1. macOS 기본 동작을 커스텀 장식보다 우선한다.
2. 큰 데스크톱 화면에서도 정보 밀도를 잃지 않는다.
3. 창 크기가 바뀌어도 텍스트, 이미지, inspector가 겹치지 않는다.
4. 선택, 포커스, 분류 대상을 서로 다른 상태로 표현한다.
5. 색상만으로 성공·실패·선택을 전달하지 않는다.
6. 원본을 변경하는 동작은 목적지와 개수를 확인한 뒤 실행한다.

## 구현 체크

AppKit 화면을 바꾸면 최소 창, 기본 창, 전체 화면에서 각각 확인한다. 고정 좌표를 사용하더라도 `windowDidResize` 또는 layout 갱신이 모든 하위 view를 다시 배치해야 하며, 첫 데이터 로드 후에도 resize 없이 올바른 위치에 나타나야 한다.
