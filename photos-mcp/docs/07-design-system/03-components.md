# 컴포넌트

## 탐색 항목

- 아이콘, 제목, 클릭 영역 사이에 명확한 내부 여백을 둔다.
- 선택 배경은 accent color의 낮은 alpha를 사용한다.
- 선택 상태는 배경, 아이콘 tint, 텍스트를 함께 바꾼다.
- 사이드바 하단 상태는 점과 두 줄 텍스트의 baseline을 맞춘 하나의 그룹으로 배치한다.

## 버튼

- 주요 동작은 accent bezel을 사용하고 화면당 우선순위를 하나로 제한한다.
- `+`, `−`, 이전, 다음처럼 아이콘 중심인 버튼도 최소 32~40pt 클릭 영역을 확보한다.
- 비활성 버튼은 이유가 주변 설명이나 현재 상태로 이해돼야 한다.
- 위험하거나 원본에 쓰는 동작은 바로 실행하지 않고 확인 단계로 이동한다.

## 카드와 상태 행

- 카드 전체가 한 작업이면 내부 버튼과 클릭 영역이 충돌하지 않게 한다.
- 상태 점 옆에는 `완료`, `실패`, `진행 중` 같은 텍스트를 함께 둔다.
- 0건 완료는 `결과 0건`으로 명시하고 “결과 보기 가능”으로 표현하지 않는다.
- 환경 검사는 최근 작업과 별도 section으로 구분한다.

## 사진 선택

사진 브라우저에는 다음 세 상태가 있다.

| 상태 | 의미 | 표현 |
| --- | --- | --- |
| 포커스 | 키보드 이동 기준 | 테두리 또는 focus ring |
| 현재 보기 | inspector에 표시한 사진 | 선택 강조 |
| 분류 대상 | 실제 분석에 포함 | 우측 상단 체크 표시 |

클릭은 현재 보기를 바꾸고, 체크박스·Enter·Space는 분류 대상 여부를 토글한다. 여러 장 선택을 위해 Command 키 동작을 추측하게 만들지 않는다.

## 사진 카드

- 이미지는 aspect fill 또는 fit 정책을 화면 역할에 맞게 일관되게 적용한다.
- 결과 카드에는 분류, 점수, 짧은 분석 이유를 유지한다.
- 전체 텍스트는 tooltip이나 inspector에서 확인할 수 있어야 한다.
- 이미지 로드는 UI thread를 막지 않고, 재사용 셀에 이전 이미지가 남지 않도록 요청 identity를 검사한다.
