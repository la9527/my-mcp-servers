# 키보드 조작

> 근거: `local_file_selection_appkit.py`, `photo_viewer_appkit.py`

## 로컬 폴더 사진 보기

| 키 | 격자 보기 | 한 장 보기 |
| --- | --- | --- |
| `←` | 이전 사진으로 focus 이동 | 이전 사진 |
| `→` | 다음 사진으로 focus 이동 | 다음 사진 |
| `Enter` | 현재 사진 분류 대상 토글 | 현재 사진 분류 대상 토글 |
| 숫자패드 `Enter` | 현재 사진 분류 대상 토글 | 현재 사진 분류 대상 토글 |
| `Space` | 현재 사진 분류 대상 토글 | 현재 사진 분류 대상 토글 |

방향키 이동은 보고 있는 사진만 바꾸며 기존에 체크한 분류 대상을 해제하지 않는다.

## 접근성 원칙

- 모든 icon button은 한국어 accessibility label을 가진다.
- 키보드 focus는 현재 보기 pane에 유지한다.
- 선택 변경 뒤에도 같은 사진이 Inspector에 유지된다.
- 비활성 이전·다음 버튼은 경계 위치를 명확히 나타낸다.

## 일반 macOS 조작

창 닫기, 전체 화면, 메뉴 탐색은 macOS 표준 단축키를 따른다. 앱 종료와 daemon 정지는 동일하지 않을 수 있으므로 서버 운영은 메뉴 막대 상태 메뉴에서 확인한다.
