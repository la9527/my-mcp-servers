# 키보드 조작

> 근거: `local_file_selection_appkit.py`, `photo_viewer_appkit.py`

## 로컬 폴더 사진 보기

| 키 | 격자 보기 | 한 장 보기 |
| --- | --- | --- |
| `←` | 이전 사진으로 focus 이동 | 이전 사진 |
| `→` | 다음 사진으로 focus 이동 | 다음 사진 |
| `Enter` | 현재 사진 분류 대상 토글 | 현재 사진 분류 대상 토글 |
| 숫자패드 `Enter` | 현재 사진 분류 대상 토글 | 현재 사진 분류 대상 토글 |
| `Space` | 현재 사진 분류 대상 토글 | 현재 사진 분류 대상 토글 |
| `Command` + `+` | 해당 없음 | 현재 보이는 사진 영역의 중앙을 기준으로 확대 |
| `Command` + `−` | 해당 없음 | 현재 보이는 사진 영역의 중앙을 기준으로 축소 |

방향키 이동은 보고 있는 사진만 바꾸며 기존에 체크한 분류 대상을 해제하지 않는다.
한 장 보기의 더블클릭, pinch, `Command` + scroll, 확대 상태 drag는 전체 화면 사진 뷰어와 동일하게 동작한다.

## 전체 화면 사진 뷰어

| 입력 | 동작 |
| --- | --- |
| `←`, `→` | 이전·다음 사진 |
| `Escape` | 뷰어 닫기 |
| `Command` + `+` | 현재 보이는 사진 영역의 중앙을 기준으로 확대 |
| `Command` + `−` | 현재 보이는 사진 영역의 중앙을 기준으로 축소 |
| 더블클릭 또는 trackpad smart zoom | 클릭 위치 기준 확대 또는 화면 맞춤 복귀 |
| pinch | 제스처 중심 기준 연속 확대·축소 |
| `Command` + scroll | 포인터 위치 기준 단계 확대·축소 |
| 확대 상태에서 drag | 사진 이동 |

일반 scroll은 확대가 아닌 사진 이동이다. 확대·축소가 필요한 사용자는 toolbar의 `축소`, `확대`, `화면 맞춤`, `100%` control도 사용할 수 있다.

## 추천 품질·인물 구성 검토

| 입력 | 추천 품질 검토 | 인물 구성 검토 |
| --- | --- | --- |
| `←`, `→` | 이전·다음 장면 | 이전·다음 장면 |
| `Enter` | 현재 1·2순위 저장 후 다음 장면 | 선택한 인물 구성 저장 후 다음 장면 |
| 사진 클릭 | 사람 평가 1순위 선택 | 큰 사진 보기 |
| `Shift` + 숫자 | 해당 사진을 2순위로 토글 | 해당 없음 |
| `0` | 1·2순위 선택 해제 | 해당 없음 |

인물 구성 검토에서 결정을 내리기 어렵다면 `판단 보류`를 선택한 뒤 `Enter`로 저장한다. 이름을 입력하거나 사람을 식별할 필요는 없다.

## 접근성 원칙

- 모든 icon button은 한국어 accessibility label을 가진다.
- 키보드 focus는 현재 보기 pane에 유지한다.
- 선택 변경 뒤에도 같은 사진이 Inspector에 유지된다.
- 비활성 이전·다음 버튼은 경계 위치를 명확히 나타낸다.

## 일반 macOS 조작

창 닫기, 전체 화면, 메뉴 탐색은 macOS 표준 단축키를 따른다. 앱 종료와 daemon 정지는 동일하지 않을 수 있으므로 서버 운영은 메뉴 막대 상태 메뉴에서 확인한다.
