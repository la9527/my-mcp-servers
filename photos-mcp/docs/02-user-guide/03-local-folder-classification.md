# 로컬 폴더 분류

> 근거: `local_file_selection_appkit.py`, `raw_image.py`, `vendor/photo-source/sources/local_folder.py`

## 화면 구조

로컬 폴더 브라우저는 세 영역으로 구성된다.

```text
┌ 폴더 트리 ┬ 사진 격자 또는 한 장 보기 ┬ Inspector와 작업 설정 ┐
│ 즐겨찾기  │ 검색·정렬·보기 밀도       │ 현재 사진 미리보기    │
│ 위치      │ 사진 선택 checkbox        │ 파일 정보              │
│ 하위 폴더 │ 전체 선택·해제            │ 실행 옵션              │
└───────────┴───────────────────────────┴───────────────────────┘
```

왼쪽 pane은 창 폭의 최대 약 40%까지 확장할 수 있어 깊은 경로를 확인할 수 있다. 중앙 pane은 남은 공간에 맞춰 사진을 aspect-fit으로 표시한다.

## 폴더 탐색

- `+` 버튼으로 접근할 위치를 추가한다.
- 폴더 disclosure를 펼쳐 하위 경로를 탐색한다.
- `하위 폴더 포함`을 사용하면 선택 폴더 아래 사진을 함께 검색한다.
- 이전·다음 폴더 버튼으로 탐색 기록을 이동한다.
- 검색은 현재 표시 결과의 파일명을 필터링한다.

원본 폴더는 읽기 전용으로 사용한다.

## 사진 보기

### 격자

- 사진을 클릭하면 Inspector focus가 이동한다.
- 우상단 checkbox는 분류 대상을 독립적으로 선택한다.
- `-`와 `+`로 thumbnail 밀도를 조절한다.
- 정렬은 최신순, 오래된순, 파일명, 파일 크기를 지원한다.

### 한 장

- 선택한 사진을 중앙 pane에 크게 표시한다.
- 좌우 이동 버튼 또는 방향키로 사진을 탐색한다.
- 현재 순번과 전체 사진 수를 확인한다.
- 더블클릭 또는 trackpad smart zoom으로 선택한 지점을 중심으로 확대하고, 다시 실행하면 화면 맞춤으로 복귀한다.
- 확대 상태에서 사진을 끌면 잡은 지점이 포인터를 따라 이동한다. 일반 scroll은 이동, `Command` + scroll과 pinch는 포인터 위치 기준 확대·축소다.
- `−`, `+`, `화면 맞춤`, `100%` 버튼을 제공하며 새 사진으로 이동하면 화면 맞춤으로 초기화한다.

## 선택과 focus

보고 있는 사진과 분류 대상은 별도 상태다. 사진 본문을 이동해도 체크된 대상은 유지된다. 체크박스, `Enter`, `Space`만 분류 대상 상태를 바꾼다.

## RAW 지원

SONY `.ARW` 등 macOS ImageIO가 지원하는 RAW 파일은 embedded preview 또는 thumbnail을 추출해 표시한다. 미리보기 생성은 원본을 수정하지 않으며, 분석 입력이 필요할 때 화면 목적에 맞게 축소한다.

지원하지 않는 파일은 목록에서 제외하거나 미리보기 실패 상태로 남는다. 파일 확장자만으로 이미지라고 가정하지 않고 실제 디코딩 가능 여부를 확인한다.

## 실행

1. 사진을 체크한다.
2. 오른쪽에서 작업 방식, 프로필, 최대 처리 수를 확인한다.
3. `선택한 N장 분류`를 누른다.
4. 시작된 작업은 작업 기록에서 추적한다.

최대 처리 수보다 많이 선택하면 실행할 수 없으며 선택 수를 줄이거나 limit을 변경해야 한다.
