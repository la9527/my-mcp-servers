# 앱 화면 안내

> 근거: `main_window_appkit.py`, `menu_app.py`

## 메인 창

Photos MCP의 일반 작업은 메인 창에서 수행한다.

| 탭 | 역할 |
| --- | --- |
| 홈 | 서버 상태, 사진 분류 진입, 최근 작업, 환경 요약 |
| 사진 분류 | Apple 사진 범위 또는 로컬 폴더 선택 |
| 작업 기록 | 진행·완료·실패 작업과 결과 진입 |
| 환경 및 권한 | 사진 접근, 읽기, 선택 검사, VLM 상태 |

왼쪽 sidebar 하단에는 서버 실행 상태와 사진 보관함 연결 상태가 표시된다.

## 메뉴 막대 상태 항목

메뉴 막대 항목은 작업 화면이 아니라 서버 운영용이다.

- 메인 창 열기
- 서버 시작·중지·재시작
- 상태 새로 고침
- 연결 정보 확인
- 앱 종료

분류, 결과 검토와 환경 검사는 메인 창에서 수행한다.

## 창 생명주기

- 메인 창을 닫아도 명시적으로 앱을 종료하지 않으면 daemon은 계속 실행될 수 있다.
- 분석 작업은 분류 입력 창과 독립적으로 저장된다.
- 완료 결과는 작업 기록에서 다시 연다.
- 앱 재시작 뒤 중단 작업은 사용자 승인 없이 자동 재개하지 않는다.

## 화면 상태 표현

색상만으로 상태를 구분하지 않는다.

- 녹색과 `준비` 또는 `완료`
- 노란색과 `확인 필요` 또는 대기 원인
- 빨간색과 사용자용 실패 설명
- 회색과 미실행·비활성 상태

내부 provider ID나 절대 파일 경로는 일반 목록보다 상세 진단에서만 확인한다.
