# Apple 사진 분류

> 근거: `direct_classification.py`, `direct_classification_appkit.py`, `apple_photos_runtime.py`

## 범위 선택

`사진 분류` 탭에서 Apple 사진 영역을 사용한다.

1. 앨범을 선택한다. 전체 보관함도 가능하다.
2. 기간이 필요하면 `기간 지정`을 켜고 시작일·종료일을 입력한다.
3. 작업 방식을 선택한다.
4. 분류 프로필과 최대 분석 수를 선택한다.
5. `범위 확인`으로 예상 사진 수와 다운로드 필요 수를 확인한다.
6. `분류 시작`을 누른다.

## 작업 방식

- 사진 분류: 사진마다 category와 설명, 점수를 만든다.
- 우수 사진 선별: 품질과 장면 유사성을 바탕으로 대표 후보를 만든다.

프로필은 일반·인물·풍경 등 입력 특성에 맞는 점수 구성을 선택한다.

## iCloud-only 사진

원본이 Mac에 없으면 즉시 분석할 수 없다. 앱은 local availability를 확인하고 필요한 경우 원본 준비 상태를 작업에 기록한다.

- 다운로드가 완료되면 작업을 이어갈 수 있다.
- timeout이나 앱 재시작이 발생하면 재개 대기로 남을 수 있다.
- 목록에서 파일 준비 원인을 확인하고 명시적으로 재개한다.

## 분석 결과

분류 작업은 Apple 사진의 원본·앨범을 변경하지 않는다. 결과 화면에서 최종 대상을 다시 선택한 뒤 별도의 내보내기 또는 앨범 추가 승인을 수행한다.

## 권한 문제

앨범이 비어 보이거나 범위 확인이 실패하면 다음 순서로 확인한다.

1. `환경 및 권한`의 사진 접근 권한
2. 사진 보관함 읽기 검사
3. Apple 사진 앱에서 원본 다운로드 상태
4. `/health/capabilities` 상세

자세한 진단은 [문제 해결](../05-operations/04-troubleshooting.md)을 참고한다.
