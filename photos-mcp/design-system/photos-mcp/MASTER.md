# Photos MCP macOS 디자인 시스템

이 문서는 `ui-ux-pro-max`, `swift-macos`, `refactoring-ui`, `ux-heuristics`의 감사 절차와 Apple Human Interface Guidelines를 Photos MCP의 실제 AppKit 구조에 맞게 조정한 기준이다. 웹 랜딩 페이지용 자동 추천은 적용하지 않는다.

## 우선순위

1. Apple 플랫폼 관례와 네이티브 컨트롤을 우선한다.
2. 작업 상태와 다음 행동을 사용자가 즉시 알 수 있어야 한다.
3. 시스템 폰트, 시스템 강조색, semantic 색상을 사용한다.
4. 4pt와 8pt 단위의 간격 체계를 유지한다.
5. 고정 이미지보다 SF Symbols를 사용한다.
6. 창 크기와 전체 화면에서 내용이 잘리거나 겹치지 않아야 한다.

## 타이포그래피

| 역할 | 크기 | 굵기 |
| --- | ---: | --- |
| 화면 제목 | 29~33pt | Semibold |
| 섹션 제목 | 18~20pt | Semibold |
| 카드 제목 | 15~16.5pt | Semibold |
| 본문·컨트롤 | 13.5~15.5pt | Regular 또는 Medium |
| 보조 정보 | 11.5~13pt | Regular |

- `NSFont.systemFont` 계열을 사용한다. 한글 글꼴을 이름으로 고정하지 않는다.
- 큰 데스크톱 창에서는 원본 의미 크기에 계층별 배율을 적용한다. 16pt 미만은 1.27배, 16~24pt는 1.2배, 24pt 이상은 1.16배로 확대한다.
- 본문과 보조 정보의 대비가 사라지지 않게 `labelColor`, `secondaryLabelColor`를 구분한다.
- 한 화면에서 제목 크기를 임의로 늘리거나 같은 계층에 서로 다른 크기를 사용하지 않는다.

## 색상과 표면

- 주 동작: `NSColor.controlAccentColor`
- 성공: `NSColor.systemGreenColor`
- 경고: `NSColor.systemYellowColor`
- 실패: `NSColor.systemRedColor`
- 배경: `windowBackgroundColor`
- 카드: `controlBackgroundColor`
- 구분선: `separatorColor`
- 선택된 사이드바는 사용자의 시스템 강조색을 낮은 불투명도로 사용한다.
- 색상만으로 상태를 전달하지 않고 제목과 상태 문구를 함께 표시한다.

## 간격과 크기

- 기본 단위: 4, 8, 12, 16, 24, 32pt
- 화면 바깥 여백: 28~32pt
- 카드 내부 여백: 16~24pt
- 카드 사이 간격: 12~16pt
- 사이드바 항목 높이: 44~48pt
- 아이콘: 16, 20, 28pt 세 단계만 사용한다.
- 버튼은 네이티브 bezel과 키보드 포커스를 유지한다.

## 아이콘

- 사이드바와 상태 아이콘은 `NSImage.imageWithSystemSymbolName`으로 생성한다.
- 동일 계층에서는 outline 기반 SF Symbols를 사용한다.
- 선택 상태는 아이콘 교체가 아니라 강조색과 배경으로 표현한다.
- ImageGen PNG와 이모지, 텍스트 기호를 구조적 아이콘으로 사용하지 않는다.
- 모든 아이콘과 아이콘 버튼에는 접근성 설명을 제공한다.

## 화면별 원칙

### 홈

- 현재 서버 상태, 주 동작인 사진 분류, 최근 작업, 환경 상태 순서로 배치한다.
- 주 동작은 한 개만 강조한다.
- 완료 결과가 있으면 `결과 보기`, 진행 중이면 `작업 취소`를 노출한다.

### 사진 분류

- 입력은 `분류 범위`와 `작업 설정` 두 그룹으로 구분한다.
- 범위 요약에서 예상 사진 수, 실행 수, 다운로드 필요 수를 실행 전에 보여준다.
- 실행 중에는 버튼을 비활성화하고 상태 문구를 즉시 갱신한다.

### 작업 기록

- 목록과 상세를 나눠 사용자가 선택한 작업을 잊지 않게 한다.
- 완료, 진행, 실패를 색상과 상태 문구로 함께 구분한다.
- 결과가 없는 완료 작업에는 `결과 보기`를 노출하지 않는다.

### 환경 및 권한

- 사진 보관함 준비 상태와 이미지 분석 모델 상태를 별도 카드로 구분한다.
- Mac mini와 Linux workstation은 SF Symbols로 표현한다.
- 온디맨드 모델은 `요청 시 연결`로 표시하고 사용자가 원할 때만 연결 검사를 실행한다.
- 선택 검사는 미실행 상태와 실행 버튼을 함께 보여준다.

## 전달 전 검사

- 시스템 폰트와 SF Symbols만 사용했는가?
- 라이트 모드와 다크 모드에서 글자와 구분선이 보이는가?
- 현재 위치와 주 동작을 즉시 알 수 있는가?
- 실행 시간이 300ms를 넘는 작업에 상태 피드백이 있는가?
- 키보드 포커스 순서가 화면 순서와 일치하는가?
- 최소 창과 전체 화면에서 겹침, 잘림, 불필요한 가로 스크롤이 없는가?
- 모든 의미 있는 아이콘에 접근성 설명이 있는가?
